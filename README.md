# Singlish, lah.

A small Singlish glossary for Japanese expats living and working in Singapore — plain HTML/CSS/JS, no build step, deployed on GitHub Pages.

日本語版は下に記載しています (Japanese version below).

## What this is

Terms and phrases collected from everyday life in Singapore — some well-known Singlish staples, some picked up in real conversations and looked up afterward. Content is in Japanese, aimed at Japanese-speaking residents.

It can be read in two directions:

- **Singlish → Japanese** — search and filter the terms, for when you heard something and want to know what it meant.
- **Japanese → Singlish** — pick a feeling (surprise, complaint, apology, …) and get phrases you could say. Entries are split into ones a non-local can reasonably say and ones that are better left to be understood only, since several of these words describe other people.

Data lives in [`data/terms.json`](data/terms.json); the site is a static UI over it. It is also a PWA — installable, and the glossary works offline once visited.

Icons are generated by [`make-icons.py`](make-icons.py) (`python3 make-icons.py`), so they are not hand-edited binaries.

## Running locally

No build tools needed — just serve the folder:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## How this was written

Claude Code wrote the HTML, CSS and JavaScript in this repository. The terms in [`data/terms.json`](data/terms.json) are ones I heard in Singapore, and the Japanese explanations are mine, including any error in them.

## これは何か（日本語）

シンガポールで暮らす・働く日本人駐在員向けの、実用シングリッシュ用語集です。定番のシングリッシュ表現に加えて、実際の会話の中で遭遇して意味を調べた表現もまとめています。

引き方は2方向あります。

- **シングリッシュ → 日本語** … 聞いた表現を検索・絞り込みで引く。
- **日本語 → シングリッシュ** … 「驚く」「困った」「謝る」など気持ちから引く。各語は「✅ 自分でも言える」と「👂 聞き取れればいい」に分けてあります。相手を評する語など、日本人が使うと浮いたり失礼になりうるものがあるためです。

ビルド不要のシンプルな静的サイト（HTML/CSS/JS）で、GitHub Pagesでそのまま公開しています。PWAなので端末にインストールでき、一度開けばオフラインでも引けます。用語データは [`data/terms.json`](data/terms.json) にあり、新しい表現に出会うたびに追記していく予定です。
